# Project Rules and Context

## Problem Statement
A logistics company tracks shipment scans, delay reports, and warehouse transfer records separately, making it impossible to predict which operational routes consistently produce cascading delivery delays.

## Domain Guidance
All future tasks, datasets, data dictionaries, feature engineering scripts, models, and domain logic developed in this workspace must directly align with and support resolving this problem statement (predicting cascading delivery delays across operational routes using shipment scans, delay reports, and warehouse transfer records).
